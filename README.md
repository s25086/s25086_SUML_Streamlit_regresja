# s25086_SUML_Streamlit_regresja

Aplikacja stworzona w ramach laboratorium, wykorzystująca bibliotekę `transformers` od Hugging Face do analizy tekstu.

## Funkcje
Aplikacja oferuje dwie główne funkcjonalności:
1. Analiza wydźwięku (Sentiment Analysis): Klasyfikuje tekst angielski jako pozytywny lub negatywny. Idealne do analizy recenzji produktów.
2. Tłumaczenie (Translation): Wykorzystuje model Google T5-Small do tłumaczenia tekstów z języka angielskiego na niemiecki.
